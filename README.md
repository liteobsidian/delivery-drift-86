# Delivery Drift 86 🚗💨

Мобильная 3D-аркада про доставку товаров ночным городом. Дрифти, прыгай с трамплинов, уходи от полиции — главное, довези груз целым и заработай на новую Toyota Supra.

Стиль: Initial D встречает Asphalt — неоновый ночной город, синтезаторный саундтрек, аркадная физика дрифта.

## Играть

Открой [Delivery Drift 86](https://drift-game.liteobsidian.ru/) или собери игру локально. Игра рассчитана на iPhone в Chrome, но отлично работает и на десктопе.

## Управление

### 📱 Телефон (тач)

| Элемент | Действие |
|---|---|
| 🛞 Руль (левая часть экрана) | Удерживай и веди пальцем влево/вправо |
| ⛽ Педаль газа | Удерживай для разгона |
| 🛑 Педаль тормоза | Удерживай для торможения и дрифта задним ходом |
| ⚡ ДРИФТ | Ручник — зажми в повороте, чтобы сносить заднюю ось |

### 💻 Десктоп

| Клавиша | Действие |
|---|---|
| `W` / `↑` | Газ |
| `S` / `↓` | Тормоз / задний ход |
| `A` `D` / `←` `→` | Руль |
| `Space` | Ручник (дрифт) |
| `Esc` | Пауза |
| `M` | Звук вкл/выкл |

## Геймплей

- **Заказы**: выбирай из трёх заказов с разной платой и срочностью, доезжай до точки назначения.
- **Повреждения**: груз и машина страдают на брусчатке, в лужах (гидропланирование), при ударах о бордюры, здания и другие машины. Мятые бамперы, разбитые стёкла, а при сильных ударах — отваливающееся колесо (машина начинает тянуть в сторону).
- **Светофоры**: проезд на красный — штраф ₽150. Но проезд на зелёном на скорости даёт бонус!
- **Бонусы**: дрифт, прыжки с трамплинов, задевания машин без столкновения, побег от полиции.
- **Полиция**: два проезда на красный или две аварии — и за тобой выезжает патруль. Сумей оторваться — получишь ₽300.
- **Гараж**: прокачивай AE86 (мотор, шины, турбо) или копи на Toyota Supra из «Форсажа» (₽22000 и 8 доставок).

## Технологии

- **Three.js** — рендер ночного города: инстансированные здания с процедурными светящимися окнами, канвас-текстура дорог с разметкой и брусчаткой, туман, звёзды и луна.
- **Кастомная аркадная физика** — разложение скорости на продольную/боковую составляющие, ручник убивает сцепление задней оси, поверхности (брусчатка/лужи/грунт) меняют grip, переворот только при жёстком ударе в повороте.
- **Web Audio API** — синтезированный звук двигателя, скольжения, ударов и синтвейв-музыка без единого ассета.
- **Без ассетов** — вся графика генерируется кодом (canvas-текстуры, экструзия кузовов).
- Профиль игрока сохраняется в `localStorage`.

## Разработка

```bash
npm ci
npm run dev        # dev-сервер с HMR
npm run build      # production-сборка в dist/
npm run check      # проверка типов
```

## CI / CD

На pull request в `main` и push в `main` GitHub Actions проверяет типы, собирает игру и запускает браузерную проверку рендера и управления.

После успешной проверки push в `main` готовая сборка публикуется на [IT-Garage](https://drift-game.liteobsidian.ru/) по SFTP. GitHub Actions использует секрет репозитория `DRIFT_GAME_SFTP_KEY` и сверяет файлы опубликованной версии по HTTPS. Та же сборка публикуется на [GitHub Pages](https://liteobsidian.github.io/delivery-drift-86/).
